# Lesson 6: Authentication and Login Security

## Objective
Understand how websites verify users and protect accounts.

## Topics Covered
- Authentication: Verifying a user's identity.
- Authorization: Determining what a user is allowed to access.
- MFA: Using multiple types of verification.
- Password hashing: Avoiding plain-text password storage.
- Salting: Adding a unique random value before hashing.

## Key Learnings
Authentication and authorization are different.
MFA adds another layer of account protection.
Secure password storage uses suitable hashing algorithms and unique salts.

## Safety
All learning was theoretical and focused on defensive cybersecurity.
