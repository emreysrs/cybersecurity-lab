# Lesson 8: Linux Permissions and Ownership

## Objective
Understand Linux file permissions and ownership.

## Permission Types
- r = Read
- w = Write
- x = Execute

## Permission Commands
- `ls -l`: Display permissions and ownership.
- `chmod`: Change file permissions.
- `chown`: Change file ownership.

## Permission Examples
- 755: Owner has read, write and execute; group and others have read and execute.
- 644: Owner has read and write; group and others have read only.

## File Ownership
Linux files have an owner and an associated group.

## Key Learning
Understanding permissions helps administrators manage access to files and protect systems.
