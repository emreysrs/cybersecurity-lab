# Lesson 10: Linux Networking Tools

## Objective
Learn how to inspect network configuration and connections in Kali Linux.

## Commands Covered
- `ip addr`: Displays network interfaces and IP addresses.
- `ip route`: Displays routing information.
- `ping`: Tests network connectivity.
- `ss -tuln`: Displays listening TCP and UDP sockets.

## Practical Exercises
- Identified the main network interface: eth0.
- Inspected the routing table.
- Tested network connectivity.
- Inspected listening network sockets.

## Key Learning
Linux networking tools help identify interfaces, routes, connectivity and listening services.

## Safety
All exercises were performed in my own Kali Linux virtual machine.
