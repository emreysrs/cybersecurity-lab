# Lesson 7: Network Fundamentals

## Objective
Understand basic networking concepts.

## Topics Covered

### IP Addresses
Identify devices on a network.

### Network Ports
Identify services and applications running on devices.

### DNS
Translates domain names into IP addresses.

### TCP
Provides reliable data delivery between devices.

## Common Ports

| Port | Service |
|---|---|
| 22 | SSH |
| 53 | DNS |
| 80 | HTTP |
| 443 | HTTPS |
| 3000 | Development applications (example) |

## Key Learning
IP addresses, ports, DNS and TCP help devices communicate across networks.
