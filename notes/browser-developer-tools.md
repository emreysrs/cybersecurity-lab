# Lesson 4: Browser Developer Tools

## Objective
Learn how to inspect browser activity using Firefox Developer Tools.

## Topics Covered
- Inspector: examines HTML and CSS.
- Console: displays JavaScript messages and errors.
- Debugger: helps inspect JavaScript.
- Network: displays HTTP requests and responses.
- Storage: displays cookies and browser storage.

## Practical Exercise
1. Opened the local OWASP Juice Shop application.
2. Opened Firefox Developer Tools using F12.
3. Selected the Network tab.
4. Reloaded the application.
5. Inspected HTTP requests, methods, status codes and headers.
6. Used the Console to display a JavaScript message.

## Key Learnings
- HTTP requests allow browsers and servers to communicate.
- Status codes describe the result of requests.
- Request headers contain information sent by the browser.
- Response headers contain information sent by the server.

## Safety
All exercises were performed against my own local Juice Shop lab.
