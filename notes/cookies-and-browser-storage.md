# Lesson 5: Cookies and Browser Storage

## Objective
Understand how websites use browser storage.

## Storage Types
- Cookies: Can store preferences and session information.
- Local Storage: Stores data that can persist between browser sessions.
- Session Storage: Stores data for a particular tab session.
- IndexedDB: Stores structured browser data.

## Practical Exercise
Inspected the local OWASP Juice Shop website using Firefox Developer Tools.

## Observations
- Cookies: 3 entries visible.
- Local Storage: No data present.
- Session Storage: No data present.
- IndexedDB: No data present.

## Key Learning
Websites can use different storage mechanisms. Not every website uses every type.
