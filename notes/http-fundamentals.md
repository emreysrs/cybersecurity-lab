# Lesson 1 — HTTP Fundamentals

## What is HTTP?
HTTP stands for Hypertext Transfer Protocol. It allows browsers and web servers to communicate.

## Client and Server
- Client: The browser sending requests.
- Server: The application responding to requests.

## HTTP Methods
- GET: Retrieve information.
- POST: Submit information.
- PUT: Replace information.
- PATCH: Partially update information.
- DELETE: Remove information.

## HTTP Status Codes
- 200: OK
- 301: Redirect
- 400: Bad Request
- 401: Unauthorized
- 403: Forbidden
- 404: Not Found
- 500: Internal Server Error

## Practical Exercise
Used Firefox Developer Tools and the Network tab to observe HTTP requests made by the local OWASP Juice Shop application.

## What I Learned
Browsers send HTTP requests, servers process them, and responses contain status codes and data.
