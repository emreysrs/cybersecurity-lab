# Kali Linux Cybersecurity Lab

## Overview
This repository documents my personal cybersecurity learning environment, built using Kali Linux, Docker, and OWASP Juice Shop.

## Lab Environment
- **Operating System:** Kali Linux
- **Virtualization:** VMware Fusion
- **Container Platform:** Docker
- **Practice Application:** OWASP Juice Shop

## Objectives
- Learn Linux fundamentals and command-line tools.
- Understand Docker and containerization.
- Explore web application security concepts.
- Practice identifying common web vulnerabilities in an authorized local lab.
- Document cybersecurity learning progress.

## Lab Setup
OWASP Juice Shop is running locally in Docker.

Local address: `http://localhost:3000`

The application is bound to `127.0.0.1` to keep it accessible only from the local machine.

## Safety
All security testing is restricted to my own local lab environment. No third-party systems are tested.
